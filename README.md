# Credit Card Fraud Detection Using Machine Learning

## Project Overview

Credit card fraud has become one of the biggest challenges for financial institutions due to the rapid increase in online transactions. This project applies supervised machine learning algorithms to classify transactions as legitimate or fraudulent.

The project compares multiple machine learning models and evaluates them using various performance metrics.

## Dataset

The project uses the **Credit Card Fraud Detection Dataset** available on Kaggle.

Dataset contains:

- 284,807 transactions
- 31 features
- Binary classification
- Highly imbalanced dataset
